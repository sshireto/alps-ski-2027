# NYC → Catskills itinerary

A self-contained, mobile-friendly two-day itinerary from New York City to Harriman State Park and the Catskills for September 11–12, 2026.

Published with GitHub Pages at: https://sshireto.github.io/alps-ski-2027/nyc-catskills/

The page includes hotel links, hiking and mountain options, photographs, Google Maps directions, a budget calculator, saved notes, a checklist, printing, downloading, and link sharing. External photographs, maps, and booking references require an internet connection.
